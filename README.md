# V8 Simulations — 2 × R4

Interaktywny symulator brzmienia hipotetycznego silnika V8 złożonego z dwóch niezależnych silników R4.

## Funkcje
- Obroty 800–12 000 RPM.
- Regulacja fazy zapłonu drugiego R4: 0–90°.
- Porównanie rytmu 90°/90° oraz 30°/150°.
- Syntetyczne impulsy demonstracyjne.
- Wczytanie lokalnego nagrania WAV/MP3/M4A, wybór początku i długości impulsu.
- Podgląd przebiegu wybranego fragmentu.
- Obsługa na telefonie w przeglądarce obsługującej Web Audio.

## Uruchamianie
Otwórz `index.html` w przeglądarce lub opublikuj repozytorium przez **Settings → Pages → Deploy from a branch → main / (root)**.

## Nagranie
Przykładowe nagranie jednocylindrowego motocykla: [Honda CRF250M na Freesound](https://freesound.org/people/richwise/sounds/517605/). Plik należy pobrać i wczytać w interfejsie. Nie jest dołączony do repozytorium.

## Ograniczenia
To eksperyment akustyczny, a nie fizycznie dokładny model silnika i układu wydechowego. Fragment prawdziwego nagrania należy ręcznie dobrać, a wynik zależy od jakości próbki i rezonansów obecnych w oryginale. Dane audio są przetwarzane lokalnie w przeglądarce.
